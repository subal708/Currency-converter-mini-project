# 💱 Currency Converter

A simple and interactive currency converter web application built using **HTML, CSS, and JavaScript**. It uses an exchange-rate API to convert an amount from one currency to another.

## ✨ Features

- 💰 Enter an amount to convert
- 🌍 Select source and target currencies
- 🔄 Swap the selected currencies
- 📊 Display the exchange rate
- 🚩 Show currency flags
- 🌐 Fetch exchange rates using an API
- 🎨 Clean and visually appealing user interface

## 🛠️ Technologies Used

- **HTML5** — Structures the application.
- **CSS3** — Styles the interface and layout.
- **JavaScript** — Handles currency selection, API requests, and conversion logic.
- **Currency API** — Retrieves exchange-rate data.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- An internet connection to fetch exchange rates

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## 🔗 API Used

This project uses the following currency API endpoint:

```text
https://2024-03-06.currency-api.pages.dev/v1/currencies
```

The API provides currency exchange-rate data used by the application to calculate conversions.
